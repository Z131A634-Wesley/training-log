## 1. 产品与用户

一句话：**在健身房里单手记完，回家在电脑上看趋势的私人训练日志。**

| 维度 | 事实 | 对设计的约束 |
| --- | --- | --- |
| 主要设备 | 手机，单手握持 | 主操作按钮放拇指区，命中区 ≥ 44px |
| 使用场景 | 器械之间，可能戴手套、灯光复杂、停留 30–60 秒 | 一屏内完成「填动作 → 保存」，不滚动也能保存 |
| 次要设备 | 电脑，回看为主 | 大屏展示历史与热力图，信息密度可以更高 |
| 数据量 | 一年 100–200 条训练 | 列表不需要分页、搜索、筛选 |
| 情绪基调 | 冷静、有累积感，不鸡血 | 不要霓虹、不要渐变高亮、不要庆祝动画 |

**最重要的结论：这是一个工具页，不是一个落地页。**
当前页面的问题不是配色难看，而是**用落地页的手法做工具页**：大标题、英文眉题、装饰数字、三段重复的 CTA。工具页的层级应该由**字号与留白**建立，而不是由装饰元素建立。

逐条举证，都可以在代码里定位：

| # | 症状 | 证据 |

| 4 | 字号没有体系 | 页面里出现 9、10、11、12、13、15、16、19、22、23、25、26、30、43、52、64 共 16 种字号 |

| 7 | 一个绿色承担所有语义 | 主按钮、热力图、选中态、备份卡底色全是同一族绿，颜色没有分工 |

| 10 | 对比度偏低 | `#a0aca0` 在白底约 2.6:1，小字几乎看不清 |
| 11 | 三段重复 CTA | 顶栏、首屏、历史标题旁各有一个「记录训练」 |

**一句话结论：装饰多于信息，层级靠 1px 线而不是字号。**

## 3. 设计方向：编辑型工具（Editorial Utility）

三个关键词：**纸、墨、一个记号。**

- **纸**：暖白底，靠色温而不是纹理制造质感。不加背景图、不加噪点。
- **墨**：文字与主按钮用近黑。深绿只作"动作色"，不大面积铺底。
- **一个记号**：赤陶色（`--today`）**只**用于"今天 / 当前选中 / 当前编辑中"，每屏出现不超过 2 处。这是整个页面唯一的暖色，用来把视线钉在"今天"上。

### 明确排除的路线

| 路线 | 为什么不选 |
| --- | --- |
| 玻璃拟态（glass.samasante.com） | 健身房环境光复杂，半透明会直接吃掉文字可读性；且项目没有图片层，玻璃没有内容可透 |
| 3D 图标（3dicons.co） | 单页工具用不上图标体系；一张 3D 图 = 100KB+，换不来信息 |
| 暗色模式 | V1 范围外，且热力图色阶要重做一遍 |
| 视差 / 滚动叙事（scrolltide.co 的进阶部分） | 工具页没有叙事；滚动劫持在手机上只会让人记不住位置 |
| 全屏视频 / WebGL 首屏（supahero 的部分案例） | 首屏要让位给「记录一次训练」 |

**热力图色阶（与品牌色分开，单独一套）**

| 令牌 | 值 | 含义 |
| --- | --- | --- |
| `--level-0` | `#E7E9E2` | 0 组 |
| `--level-1` | `#C9DBC2` | 1–5 组 |

> 对比度是估算值，实施时用 DevTools 复核，正文必须 ≥ 4.5:1。

### 5.2 字体

**分工：英文与数字用 Inter，中文走系统字体。**

- 不引入中文 Web 字体：一份中文子集 3–5MB，与"加载速度快"直接冲突，且 GitHub Pages 无法按需裁剪。
- Inter 自托管 latin 子集（woff2 ≈ 15–20KB），只覆盖数字、英文、符号；`font-display: swap`。
- 中文回退栈：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui`。

```css
--font-ui: Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--font-num: Inter, ui-monospace, "SF Mono", monospace; /* 数字用 tabular */
```

数字规则：所有会变化的数字（组数、重量、统计）加 `font-variant-numeric: tabular-nums;`，避免跳动。

**字号阶梯只有 6 档**（这是硬约束，不允许中间值）：

| 层级 | 字号 / 行高 | 字重 | 字距 | 用在哪 |
| --- | --- | --- | --- | --- |
| display | `clamp(40px, 6vw, 56px)` / 1.05 | 500 | -0.03em | 首屏标题，**全站只有这一处** |
| h2 | 32px / 1.2 | 600 | -0.02em | 区块标题 |
| h3 | 20px / 1.4 | 600 | -0.01em | 卡片标题、日期 |
| body | 15px / 1.75 | 400 | 0 | 正文、表单标签说明 |
| small | 13px / 1.6 | 400 | 0 | 辅助信息、按钮文字 |
| micro | 11px / 1.4 | 500 | 0.02em | 标签、图例 |

中文排版：行高不低于 1.7（正文）、字距 0、不强制两端对齐。

### 5.3 间距

4px 基准，只用这九档：

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
```

- 组件内部：4、8、12
- 组件之间：16、24
- 区块内部：24、32
- 区块之间：48（手机）/ 64（平板）/ 96（桌面）

### 5.4 圆角、描边、阴影

| 对象 | 圆角 |
| --- | --- |
| 热力图格子 | 2px |
| 按钮、输入框、徽标 | 8px |
| 卡片、面板、对话框 | 12px |
| 计数胶囊 | 999px |

- 描边：默认 `1px solid var(--line)`；输入框用 `--line-strong`。
- 阴影：**默认没有阴影**。只有对话框用一层：
  `box-shadow: 0 24px 48px -24px rgb(25 27 24 / 0.28);`
- 卡片 hover **不加阴影、不加位移**（列表会跳），只把描边换成 `--line-strong`。

### 5.5 动效

```css
--ease: cubic-bezier(0.2, 0.8, 0.2, 1);
--dur-hover: 120ms;
--dur-enter: 240ms;
```

只允许三种动效，详见第 8 节。

## 7. 页面结构与组件

### 7.1 Navbar

- 高度 64px（手机 56px），单行，**不使用 sticky**（页面短，粘住反而挡内容）。
- 左：品牌（纯文字，去掉方块图标和 `↗`）；中：无；右：日期（`micro` 级，`--ink-3`）+ 主 CTA「记录训练」。
- 滚动后只增加底部 `1px solid var(--line)`，**不加毛玻璃**。
- 手机：隐藏日期，只留品牌 + 一个 44px 高的按钮。

### 7.2 Hero

- 目的：让人 3 秒内知道"这是什么、点哪里"。
- 结构：`display` 级标题（1 行中文，不用 `<br>` 硬断）→ 一行说明（`body`，`--ink-2`）→ 主按钮。
- 右侧数据块用 `h3` + `micro` 标签，数字 `tabular-nums`。
- 不做：英文眉题、状态圆点、副标题两行以上、任何背景装饰。

### 7.3 记录（TrainingForm）

- 默认收起，点 CTA 后在 Hero 下方展开（保留现有交互，符合"打开就填"的心理）。
- 展开有 200ms 的高度/透明度过渡；`prefers-reduced-motion` 下直接出现。
- 表单内部：日期单独一行（宽 200px，手机满宽）→ 每个动作一张 `--surface-sunk` 卡（12px 圆角，16px 内边距）→ 添加动作（虚线按钮）→ 底部右对齐「保存」。
- 字段标签 `micro` 级、`--ink-2`；输入框 44px 高、8px 圆角、`--line-strong` 描边、聚焦时描边变 `--today` 并加 2px 外发光（`box-shadow: 0 0 0 3px rgb(180 83 42 / .16)`）。
- 校验错误：在字段下方 `small` 级红字，同时把焦点送到出错字段（现状已实现，保留）。
- **手机端**：表单展开后，底部固定一条 56px 的「保存训练」条（避免在长表单里找按钮）。

### 7.4 热力图

- 格子 12px（桌面）/ 16px（`pointer: coarse`），间距 3px，圆角 2px。
- 今天：`--today` 的 1px 内描边；选中：2px 内描边 + `--today`。
- 图例用 `micro`，只写「少 / 多」两端，中间五格不写字。
- 键盘：保留现有 roving tabindex + 方向键；焦点环 2px、`--today`。
- 统计条：三列，数字 `h2` 级，标签 `micro`，中间用 `--line` 竖线分隔；手机端改为三行等宽。

### 7.5 历史

- 从"每次训练一张卡"改为**按日期分组的列表**：日期行（`h3` + 组数胶囊）+ 该日训练条目。
- 条目行：动作名（`body` 600）+ 备注（`small`，`--ink-3`）+ 右侧 `重量 × 组数`（`tabular-nums`）。
- 编辑/删除：默认 `--ink-3`，hover/焦点时变 `--ink`；触屏常显。
- 空状态：一行说明 + 一个文字按钮，不用大图标块。

### 7.6 备份与 CTA

- 备份从"绿色 callout 卡"降级为**普通区块**：标题 + 一行说明（数据只在这台设备）+ 两个文字按钮（导出 / 导入）。
- 全站主 CTA 只保留 **2 处**：Navbar 一处、Hero 一处。历史区标题旁的「新增记录」改为文字按钮。
- CTA 上下留白 48px（手机）/ 64px（桌面）。

### 7.7 Footer

- 单行：`训练日志` · `数据保存在这台设备` · 年份。
- `micro` 级，`--ink-3`，顶部 1px 线，上下 32px。
- 不放导航、不放社交、不放第二个 `↗`。

## 8. 动效与滚动

| 场景 | 参数 | 说明 |
| --- | --- | --- |
| 控件 hover / 焦点 | 120ms，颜色与描边 | 只变颜色，不缩不放 |
| 表单展开 / 收起 | 200ms，`opacity` + `translateY(-4px)` | 用 `@starting-style` 或 `<Transition>` |
| 区块进场 | 240ms，`opacity 0→1` + `translateY(8px→0)` | IntersectionObserver，阈值 0.2，**只播一次** |
| 保存成功 | 240ms，新条目背景闪一次 `--surface-sunk` | 不做彩带、不做缩放弹跳 |

强制约束：

1. 只允许动 `transform` 和 `opacity`；不动 `width/height/top/left`（表单展开除外，且必须用 `grid-template-rows` 而不是高度动画）。
2. `@media (prefers-reduced-motion: reduce)` 下所有时长归零。
3. 全站进场动效**最多两种**（区块进场 + 表单展开），不允许再增加。
4. 不劫持滚动、不做滚动进度条、不做 sticky 视差。

## 9. 禁止清单

出现任意一条，就算不合格：

- 全大写英文小标题超过 1 处（目标：0 处）
- 装饰性编号（01/52、No.03）、装饰性箭头（↗ ⇒ →）当花纹用
- 渐变文字、渐变按钮、彩虹描边
- 玻璃拟态、毛玻璃导航
- 3D 图标、插画、emoji 当图标（✨ 🚀 💪）
- 一屏之内出现三种以上圆角
- hover 没有过渡
- 同一屏出现两个同权重的主按钮
- 用颜色承载唯一语义（比如只用颜色区分「今天」，要有描边或文字配合）

## 12. 未决问题

1. **Inter 是否自托管**：自托管需要把 woff2 放进 `public/fonts/`，会增加仓库体积约 20KB；走 CDN 则多一次跨域请求。倾向前者，待定。
2. **首屏右侧数据块放什么**：候选是「本周次数 / 累计组数 / 最近一次训练」或「连续训练天数」。后者更激励，但计算规则（中断怎么算）要在计划里先定义。
3. **历史按日期分组后，同一天的多次训练如何区分**：候选是「训练 1 / 训练 2」小标签，或按保存时间排序后不区分。倾向后者，需要在实现时确认可读性。
4. **移动端底部保存条**是否与浏览器地址栏冲突，需要真机验证一次（iOS Safari）。
